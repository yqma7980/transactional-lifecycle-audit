# Data dictionary

- `case_result.json`: frozen per-case classification and numerical gates.
- `case_manifest.json`: hashes and environment metadata for one formal run.
- `*_event_log.csv`: ordered lifecycle or physical-event ledger.
- `*_comparison.csv`: reference, replay, provenance, or path comparison.
- `*_final_summary.json`: layer-level bounded evidence summary.
- `*_execution_manifest.json`: immutable raw-file inventory.
- `S_n`: non-wetting saturation in the frozen L4/L5 displacement problem.
- `mass_defect`: discrete balance residual under the layer's frozen definition.
- `front_location`: frozen front metric; not a field-scale CO2 plume extent.
- `committed_fingerprint`: accepted history identity.
- `candidate_fingerprint`: trial state identity; not accepted unless explicitly committed.
- `OBSERVED-L5`: frozen independent-code benchmark evidence only.
- `OBSERVED-EXTERNAL-HOST`: frozen SciPy-host lifecycle replay evidence only.
- `OBSERVED-PERFORMANCE-D1`: controlled single-thread cost measurement, not a scaling claim.
