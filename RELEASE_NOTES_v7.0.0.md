# v7.0.0: retained equal-information and admission evidence

This release closes the public coverage gap for the retained Route A comparison
and admission records without changing scientific results or repeating studies.

- Adds `studies_route_a`: the frozen LCMA core and selected strong baseline,
  projection/contract/evaluation source, native adapters and recipes, all 24 saved
  native observations, eight saved evaluation outputs, original timing batches,
  and source/environment identities.
- Adds prespecified Click/Trio screening, final Click semantic-binding HOLD,
  Trio provenance HOLD, and retained negative preflight/depth evidence.
- Removes local machine/user prefixes in public copies only; source-to-public
  hashes and transformations are indexed. Records are not claimed byte-identical
  where redacted. Core, selected baseline and shared method inputs remain exact.
- Includes a standard-library read-only verifier. Verification is not a new
  native reproduction, evaluator benchmark or independent human review.
- Preserves 6/6 vs 6/6, 0/18 vs 0/18, approximately 2.171/2.164 slower, two lineages,
  all HOLD dispositions, and deep-nesting failures. No superiority claim.
- Preserves every earlier release/tag. Existing v6.0.0 data/software DOIs remain
  valid for their old scope. This release's code and derived evidence are archived
  together through the existing GitHub-Zenodo integration; it is not a silent
  replacement of the separately deposited v6 data record.

Read `studies_route_a/README.md` before use. Historical native orchestration
requires exact upstream sources, matching runtimes and path rebinding. A complete
portable native rerun was not tested, and exact timing is machine-dependent.
Third-party source trees/binaries, user-profile/comment collections, private
engineering inputs and manuscript files are not added.
