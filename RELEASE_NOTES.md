# Release notes

## v1.0.0 - 2026-07-24

Initial public reproducibility-software release for transactional lifecycle auditing of path-dependent nonlinear computational models.

### Included

- Open two-dimensional finite-element lifecycle benchmark (`FEH_D0`).
- Mutation-strength benchmark and reporting contract (`MUT_D0`).
- Frozen specifications, acceptance gates, case matrices, tests, and authorization-locked runners.
- Exact manuscript supplementary-software archive and its expanded file manifest.
- Citation, authorship, licensing, data-boundary, and checksum metadata.

### Evidence boundary

This release supports standalone lifecycle-verification claims only. It does not establish Abaqus behavior, production UEL correctness, thread safety, two-way flow-mechanics coupling, or carbon-storage predictions.
