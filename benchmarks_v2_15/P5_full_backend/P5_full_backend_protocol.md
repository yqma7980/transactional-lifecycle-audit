# P5 full FE backend protocol

Status: `IMPLEMENTED_NOT_EXECUTED`

The backend reuses the protected P4d.2 DOLFINx/PETSc constitutive law, mesh, committed-state implementation, nonlinear host and mechanics gates without editing them. P5 adds only an author-owned audit adapter, fixed arithmetic reductions, the four frozen negative-control bindings, metric extraction, calibration/selection logic and guarded runners.

The full formal protocol remains the seven frozen cases and 90 planned fresh processes. Six exact-null runs precede six A/B arithmetic calibration runs; two A/C confirmation runs use, but do not refit, the frozen threshold. Each of four fault families then executes all 15 strengths. If the predeclared selector finds an eligible adjacent pair, two new processes are run at each level.

Arithmetic A, B and C reduce the same stored element residual and tangent terms. They do not alter the FE solve, candidate selection, committed state, material update or accepted output. Structural owner, restoration, source and reachability verdicts remain exact. Numerical thresholds apply only to the eight frozen numeric metrics.

No case was executed while implementing this package. Formal execution requires a separate authorization and both runner locks. P4d native rejected line-search coverage remains `NOT_SUPPORTED_BY_DIAGNOSTIC_ENVELOPE`; P5 does not reinterpret or replace it.
